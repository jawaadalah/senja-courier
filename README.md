Senja Courier — a dusk island-courier flight game: fly the gold rings, land on the lit island airstrips, and mind your fuel. Three legs across the archipelago (dusk mail run, night medicine leg, storm leg home), with a lit HUD (altitude, speed, heading, fuel, damage), throttle/pitch discipline, and soft-landing bonuses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — keyboard (↑/↓ throttle, ←/→ pitch) and mouse (click to start, drag the throttle slider). Screenshots are real renders of the game (`?shot=start|play|ring|land`).
